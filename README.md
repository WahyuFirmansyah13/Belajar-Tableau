# Belajar Tableau 📊

Repositori ini berisi kumpulan file dan project hasil pembelajaran saya dalam menggunakan Tableau untuk visualisasi data.

## 📁 Struktur Folder

- **Tableau/Dataset/**  
  Berisi dataset mentah (.csv, .xlsx) yang digunakan dalam latihan visualisasi.

- **Tableau/Project/**  
  Berisi file project Tableau (.twb / .twbx) hasil eksplorasi dan tugas.

## 🎯 Tujuan

Sebagai dokumentasi proses belajar saya di bidang data visualization menggunakan Tableau, serta membangun portfolio sebagai calon Data Analyst.

## 🛠 Tools yang Digunakan

- Tableau Public
- Microsoft Excel (untuk olah data dasar)
- GitHub (untuk version control dan publikasi)
